# The user's own drawing habits (always on)

These rules apply to every figure this user asks for. Where they conflict with the corpus defaults, these rules
win. The print floors still apply.

## Look

- The figure must not look drawn by AI. Do not use a tinted card with a border for every group or many boxes
  that are all the same. Use as little decoration as possible: a pale background without a border is enough to
  group parts.
- One font size for all labels, and boxes sized to fit their text.
- Space must be even. Equal gaps, nothing touching, no large empty areas.

## Encoding

- Use the conventions that readers already know (for example, fire/snowflake for trainable/frozen) rather than
  inventing colour codes. Put a mark on the thing it describes.
- One meaning per visual channel: one line style for one kind of flow, one colour for one role. Apply each
  without exceptions in the whole figure.
- Keep routes simple and aligned. Draw a separate line for each target instead of a line that branches.
- One legend, in one place. A legend replaces labels that repeat on many elements.

## Content

- Leave out any detail the reader does not need. Every input must show where it comes from.
- Numbered markers go on the things the text refers to, and every marker needs a call-back in the text.
- When reviewers found a part unclear, make the figure answer that question directly.

## Consistency

- All figures of a paper share one set of icons, colours, line widths and font. Reuse the user's existing assets
  (slides, earlier figures) before drawing new ones.

## Working with this user

- Show a rendered PNG after every round of changes. Ask decisions with AskUserQuestion, in Chinese.
